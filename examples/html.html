Quickstart

      
Copy the prebuilt CSS and JavaScript beside your page. No build step is required.

      
<link rel="stylesheet" href="lightmetal.css">
<div id="editor" class="lightmetal"></div>
<script src="lightmetal.js"></script>
<script>
  const editor = lightmetal.init({
    element: document.getElementById('editor'),
    onChange: html => console.log(html)
  });
  editor.setHTML('<p>Hello, ligHTMetaL!</p>');
</script>

      
Read content with editor.getHTML() and call editor.destroy() when removing the editor. Choose toolbar controls with the actions option.

      
Use a maintained HTML sanitizer before rendering or publishing untrusted content. The editor filters HTML imports by default; Source edits and raw mode give your application direct control over HTML.
