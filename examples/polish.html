Quickstart: browser script

  
Copy the prebuilt CSS and JavaScript beside your page. The standalone build includes the complete language catalog; instances register only what you pass.

  
<link rel="stylesheet" href="polish.css">
<pre class="code theme-dark"><code id="code"></code></pre>
<script src="polish.js"></script>
<script>
  const highlighter = polish.createHighlighter({ languages: polish.allLanguages });
  document.getElementById('code').innerHTML =
    highlighter.highlight('const answer = 42;', 'js');
</script>

  
ES modules and selected languages

  
Use dist/polish.esm.js for the full-catalog module. With a bundler, import the core and just the grammars you need:

  
import { createHighlighter } from 'lightmetal/src/polish.js';
import javascript from 'lightmetal/src/polish/languages/javascript.js';

const highlighter = createHighlighter({ languages: [javascript] });
const html = highlighter.highlight('const answer = 42;', 'js');

  
Highlight MeltDown code blocks

  
const highlighter = polish.createHighlighter({ languages: polish.allLanguages });
const render = markdown => meltDown.parse(markdown, {
  highlight: highlighter.highlight
});

const editor = maiden.init({
  element: document.getElementById('editor'),
  preview: { render }
});
editor.element.querySelector('.lightmarkdown-preview')
  .classList.add('polish', 'theme-dark');

  
Load each library separately. MeltDown owns code-block wrappers; poliSH returns their highlighted contents. Themes change with CSS classes, without highlighting again. See the MaiDEn example for the complete workflow.

  
Focused tools, flexible output

  
Language aliases such as js, py, and sh work directly. Unlabelled code uses conservative guessing among registered languages; unknown explicit labels stay plain. Set guessLanguage: false to disable guessing.

  
Use ansi to convert actual terminal escape sequences, or use the token and terminal-output APIs in Node.js. ANSI colors work in standalone output; MaiDEn keeps inline styles filtered. Use a maintained HTML sanitizer for untrusted documents, and keep grammars and scanner callbacks application-controlled.
