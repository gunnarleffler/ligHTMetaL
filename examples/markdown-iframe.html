Run the whole Markdown editor in an iframe

The toolbar and writing area share one iframe. The library stays unchanged: its normal, synchronous init() runs inside that document.

Loading a sample replaces the document, not a native undo step.

Type in the editor, then in the note, and try the editor's Undo. Cross-document focus and history routing depend on the browser/runtime. Linux WebKit can undo the note instead, even across frames. Some automated Firefox runtimes also misroute parent/child input. Check your target browser before relying on iframe history isolation.
