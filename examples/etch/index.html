ligHTMetaL::Etch

Leave your mark.

Color a picture: load an image, lock its layer, then choose New layer and draw above it. The Layers ⋯ button renames/reorders/merges; the top toolbar sets the document background with a live preview. Trash deletes; Undo restores. Import drawing adds native JSON as one editable layer. Import SVG adds supported editable vectors after confirmation; unsupported artwork needs a PNG exported by your drawing app. Move Layer (M) moves only the chosen layer. Eraser (E) offers whole marks or partial Pen/line cuts. Highlighter (K) draws translucent strokes; Pen's Pressure width toggle can make stylus strokes uniform. Close the sidebar on small screens. Use Export in the editor toolbar for PNG/SVG artwork (the download shortcuts above also work); native JSON below preserves editable layers.

V: select / resize · M: move layer · P/B: pen · K: highlight · E: erase / split ink · L/A/R/O: shapes · Shift: constrain shapes · H or Space: pan · Ctrl/Cmd + wheel: zoom · Fit: recenter
